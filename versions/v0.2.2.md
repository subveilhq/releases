# Subveil v0.2.2

Subveil v0.2.2 fixes the CLI's built-in control-plane address. Masking, subsetting and loading are unchanged.

## What changed

- **The built-in API address now works.** In v0.2.0 and v0.2.1 the CLI's default control-plane address did not resolve, so `subveil login` and cloud-mode pulls failed unless you set `SUBVEIL_API_URL` or `--api-url`. The default is now `https://subveil.dev`. If you set `SUBVEIL_API_URL=https://subveil.dev` as a workaround, you can remove it.

## Upgrading

No configuration change is needed. An address you saved with `subveil login` or set in `SUBVEIL_API_URL` is still used first.

## Security and data handling

The CLI runs in your infrastructure. Source reads are read-only; raw row values are masked in process and are not sent to Subveil Cloud. Cloud features exchange metadata and audit receipts only.
