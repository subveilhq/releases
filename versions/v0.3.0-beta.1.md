# Subveil v0.3.0-beta.1 (Preview)

## What changed

- **Added:** `subveil plan --row`, with `--max-depth`, `--max-rows`, `--allow-multi-seed`, `--fail-on-truncate`, and `--json`.
- **Added:** optional `subset.row` configuration keys: `max_depth` and `max_rows`.
- **Added:** exit code 2 for row-planning limit or truncation failures and exit code 3 when a seed matches no rows.
- **Unchanged:** classic `plan` and `pull` behavior and masking output.
- **Preview limitation:** `pull --row` is not available.
