# Subveil v0.2.3

Subveil v0.2.3 makes `subveil init` finish with a short list of next steps. Masking, subsetting and loading are unchanged.

## What changed

- **`subveil init` prints next steps.** After it writes `subveil.yaml`, it prints how many tables and PII columns it found and masked, then the three commands to run next: preview the plan with `subveil plan`, pull and mask data with `subveil pull --create-schema`, and sync policies and audit receipts with `subveil login`. It does not pause to ask a question, and it exits as before. The list is not printed when you pass `--project`, because that project is already linked.

## Upgrading

No configuration change is needed. Existing `subveil.yaml` files and saved logins keep working.

## Security and data handling

The CLI runs in your infrastructure. Source reads are read-only; raw row values are masked in process and are not sent to Subveil Cloud. Cloud features exchange metadata and audit receipts only. The new summary prints counts and fixed command text, not row values.
