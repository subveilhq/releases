# Subveil v0.3.0

## Changes

- Plan and pull row-based subsets with bounded foreign-key traversal, selection limits and in-flight masking.
- Record optional pull reasons and row-selection metadata in audit receipts; cloud receipts use HMAC authentication, while local receipts are unsigned.
- Use `subveil verify` for target integrity, row-count and sampled sensitive-pattern checks. Sampling cannot prove that all sensitive data was removed.
- Use `subveil doctor` for preflight diagnostics and `subveil scan` for read-only sensitive-column discovery.
- Generate shell completion scripts for bash, zsh and fish. A Dockerfile is provided for local container builds.
- Use structured JSON output for planning and diagnostic commands.

## Validation limitations

- Large-scale row-subsetting memory use has not been verified against a defined acceptance threshold.
- Compatibility with managed database services, including Neon, RDS and Aurora, has not been independently verified for this release.
