# Subveil v0.3.0-beta.2 (Beta)

## What changed

- **Added:** `subveil pull --row`, with the same seed syntax and traversal limits as `plan --row`, plus `--reason` and optional `audit.require_reason` policy enforcement. Row pulls select in their own snapshot, mask data in flight, and check copied counts against the pull plan.
- **Added:** signed cloud and unsigned local row receipts with selection counts and metadata; seed and row values are not recorded.
- **Added:** `subveil verify` for foreign keys, unique constraints, row counts and sampled known PII and secret patterns. Sampling cannot prove the absence of sensitive data.
- **Changed:** row mode defaults to 10,000 rows and allows at most 100,000 rows and a maximum depth of 50.
- **Safety:** MySQL and MariaDB row pull targets require InnoDB. Failed row loads roll back, while schema objects created by the pull may remain.
