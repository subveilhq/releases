# Subveil v0.3.1

## Changes

- Add `--source` as an alias for `--dsn` to `init`, `plan`, and `scan`. When both flags are supplied, their values must match.
- Detect MySQL from native DSNs in `scan` and accept `mariadb` as an engine override.
- Update shell completion for the new alias and engine option.

## Validation limitations

- Large-scale row-subsetting memory use has not been verified against a defined acceptance threshold.
- Compatibility with managed database services, including Neon, RDS and Aurora, has not been independently verified for this release.
